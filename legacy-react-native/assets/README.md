# Assets

CalcMaster needs the following assets to ship:

- `icon.png` — 1024×1024 app icon (dark navy `#0B1020` background, neon "CM" mark)
- `splash.png` — 1284×2778 splash, dark background
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `favicon.png` — 48×48 web favicon

These are referenced from `app.json`. Until you generate them, run with `--no-dev` on web
to avoid the missing-asset warning.
