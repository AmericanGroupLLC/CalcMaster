Here's CalcMaster v3 — the most comprehensive version yet! Here's everything that's new and improved:

**5 Tabs** (bottom navigation):
- **Convert** — Distance, Volume, Weight, Temperature, Speed, and a new Measure tab (Area, Data storage, Pressure, Energy)
- **Calculate** — Standard, Scientific, Percentage, Base Convert, GPS, Date Diff
- **Finance** — Tax (replaces Mortgage), Tip & Split, Compound Interest, Currency
- **Tools** — BMI, Calories/BMR, Ohm's Law, ADC/DAC, Time Zones, Age Calculator
- **Notes** — Save calculations, formulas, and reminders; tap any note to edit

**Location-aware features** — tap the flag in the top-right to cycle through 🇺🇸 US, 🇬🇧 UK, 🇪🇺 EU, 🇨🇦 CA, 🇦🇺 AU, 🇮🇳 IN, 🇯🇵 JP:
- Currency defaults to your local currency
- **Sales Tax / VAT** auto-fills the correct local rate (8.5% US, 20% UK, 18% India, etc.)
- **Income Tax** uses real progressive brackets for each country — shows gross, tax owed, effective rate, and take-home pay
- Currency symbols update everywhere automatically

**Everything works live** — just type a number and results update instantly, no submit needed.

## Updated Tab Structure (Clean & Logical)

| Tab       | Tools Included (Improved Grouping) |
|-----------|------------------------------------|
| **Convert** | Distance, Volume, Weight, Temperature, Speed, **Area**, **Data Size**, **Fuel Economy**, **Pressure**, **Energy** |
| **Calculate** | Standard Calculator, Scientific Calculator, **Percentage**, Base Converter (Hex/Decimal/Binary/Octal), **Fraction** |
| **Finance** | **Tax Calculator** (main), Tip & Split, Discount, Compound Interest, **EMI/Loan**, Currency, Unit Price |
| **Tools** | GPS Coordinates, Ohm's Law, BMI, Date Difference, Time Zones, ADC/DAC, Age Calculator, Aspect Ratio |

In v4 the previous separate "Notes" tab is replaced by a global Notes modal — long-press any result row to save it, and access the full list from the bookmark icon on the Tools hub.

## v4 additions

1. **Pressure Converter** (psi ↔ bar ↔ kPa ↔ atm)
2. **Energy Converter** (Joules ↔ kWh ↔ Calories ↔ BTU)
3. **Fraction Calculator** (mixed numbers, simplification, arithmetic)
4. **Unit Price Calculator** (compares two pack sizes)
5. **Improved Tax Calculator** — quick + detailed mode, 2025–2026 brackets, filing status, standard deduction, state-tax slider, monthly + yearly take-home
